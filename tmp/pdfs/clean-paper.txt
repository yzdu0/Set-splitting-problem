                                               Abstract
        We reduce Set Splitting to exact counting for 3-CNF formulas. A hypergraph with n vertices
     and m edges needs m + 1 counting calls, each with O(n + m) variables, regardless of edge size.
     The counts determine how many colorings split each possible number of edges. Using the
     general counting bound stated in the October 2026 SAT manuscript, this gives a deterministic
     polynomial-space algorithm with running time
                                                               √
                                      |I|O(1) + 2O(k log log k/ log k) ,

     where k is the number of edges to split. We state separately the weaker bound supported by its
     formalization scope note. The reduction is proved here; the SAT counting result is assumed.


1    Problem and assumptions
A coloring splits a set if the set contains both colors. Set Splitting asks whether a coloring can
split at least k sets. There is no bound on set size. Lokshtanov and Saurabh [1] give an equivalent
instance with at most k vertices and 2k edges. Earlier specialized algorithms take O∗ (1.7171k ) time
with exponential space or O∗ (1.8213k ) time with polynomial space [2]. Here O∗ hides polynomial
factors.

Theorem 2.3 (SAT reduction). Each Ft is the satisfying-assignment count of a 3-CNF with O(n +
m + 1) variables and O(J + m + 1) clauses. The formula can be built in polynomial time.

Proof. Use color variables x1 , . . . , xn and one selector yi per edge. For each nonempty edge ei ,
choose an anchor ai ∈ ei . For every v ∈ ei \ {ai }, add

                                (¬yi ∨ ¬xai ∨ xv ),           (¬yi ∨ xai ∨ ¬xv ).                       (3)

These clauses say that selecting an edge forces all its vertices to have the same color. Empty and
singleton edges need no clauses. Add the exact-t selector count from Lemma 2.2.
    Fix a coloring x. Its allowed selector
                                      (u(x))
                                            assignments are precisely the t-element subsets of its
u(x) monochromatic edges. There are t such assignments, each with one extension to the gate
variables. Summing over x proves that the count is Ft .
    The edge constraints use at most 2J clauses and no extra variables. The selector count adds
O(m + 1) variables and clauses. The encoding length is O((J + n + m + 1) log(n + m + 2)).

   The selectors use one-way implications: a monochromatic edge may be selected or left unselected.
The gate constraints use equivalences so their extra variables do not multiply the count.
   For example, two edges {a, b} and {b, c} give

3    Running time
Theorem 3.1 (Complete distribution). Assume Countα . All coeﬃcients of PH can be computed
deterministically in polynomial space and time

                                           (L + 1)O(1) 2O(fα (n+m)) .                                   (4)

Proof. Build the formula in Theorem 2.3 for each t = 0, . . . , m and count its satisfying assignments.
Each formula has v ≤ C(n + m + 1) variables for an absolute constant C. Its length is polynomial
in L + 1, and fα (C(s + 1)) = O(fα (s)). The m + 1 calls and Lemma 2.1 add only polynomial work.
Run the calls one at a time. Their outputs and all intermediate sums have polynomial bit length,
so the total space is polynomial.

4    Extensions
Fixed colors and an optimal coloring. Add unit clauses to ﬁx any chosen vertex colors. The
same proof counts only colorings extending those choices. To ﬁnd an optimal coloring, ﬁrst ﬁnd
the largest exponent b with a positive coeﬃcient. Fix vertices one at a time. Keep color zero if
the coeﬃcient at b stays positive; otherwise keep color one. An optimum remains possible at each
step. This takes at most n + 1 distribution computations and has the same bound as (4), up to a
polynomial factor. It does not claim a target-k search algorithm for the original instance.

Families of 2-CNF formulas. Let Φ1 , . . . , Φm be 2-CNF formulas on the same n variables, with
C clauses in total. For every clause D of Φi , add ¬yi ∨ D. Selecting i now forces Φi to hold. The
exact-t selector count and binomial inversion recover the number of assignments making exactly j
of the formulas true, for every j. Each SAT call uses O(n + m + 1) variables and O(C + m + 1)
clauses, so Theorem 3.1 applies.
    This also counts assignments by the number of satisﬁed clauses in any CNF, regardless of
clause width. Use the predicate that each original clause is false: it is a conjunction of unit clauses.
Reverse the resulting distribution to count satisﬁed clauses.


5    Checks and scope
Run python3 research/verify_paper.py from the repository root. The code checks the SAT
counts against exhaustive assignments, including repeated edges, unused vertices, ﬁxed colors, and
the extensions above. Results and source hashes are in paper/verification.json.
    The tests check the reduction, not the external SAT algorithm. The polynomial identity is
established prior work [5]. No practical speedup or publication priority is claimed. The open
quantitative question is whether the ﬁxed-density SAT bound can be obtained for arbitrary edge
sizes while keeping only O(n + m) variables.
